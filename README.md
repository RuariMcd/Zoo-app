# Zoo-app
Java based console app for managing zoo animals and organising zoo information

## Overview
This project is a console based application developed in Java that allows users to manage zoo animals and information.

This project was developed to practice object oriented programming and utilises features like inheritance and polymorphism.

## Features
- Add and manage zoo animals
- Search for zoo animals
- Store information about individual animals
- View animal information
- Add and manage zoo information
- Interact with the program through a console based menu

## Technologies
- Java
- Object-Oriented Programming
- Console based interface

# Getting started

## Prerequisites
- Java Development Kit (JDK)
- A Java compatible IDE such as IntelliJ IDEA or VS Code

## Running the App
1. Download or clone the repository
2. Open the project in your preferred IDE
3. Access the "ZooApp.java" application class
4. Run the application
